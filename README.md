MapIp — Network Host Mapper
==============================

**MapIp maps the hosts on your own network.** It does not geolocate IP addresses and does not determine physical location.

Features (planned)
- ARP/ICMP/TCP host discovery
- MAC + OUI vendor, TTL/OS hint
- Name resolution (mDNS, LLMNR, NetBIOS, SSDP, SNMP)
- Port scan + banners
- Continuous monitoring + change detection (new/missing)
- SNMP switch-port mapping
- Wake-on-LAN
- HTML/CSV/JSON/Nmap XML export
- TUI (Go + bubbletea)
- CLI + local API (WebSocket)
- Electron GUI (primary)

> No geolocation. No telemetry. No third-party IP-to-location lookups.
